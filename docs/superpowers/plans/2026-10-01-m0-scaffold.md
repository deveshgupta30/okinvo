# M0 Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A bootable okinvo skeleton - pinned toolchain, DESIGN.md-driven tokens, Next 16 shell with a sign-in page, Prisma 7 schema migrated into Postgres 18, validated env, production Dockerfile + Compose, CI - such that `docker compose up` serves a themed sign-in page over Caddy and `/api/health/ready` reports the database.

**Architecture:** Single Next.js 16 app (`src/`), Prisma 7 with the `pg` driver adapter, Tailwind 4 utilities generated from `DESIGN.md`/`DESIGN.light.md` through `scripts/design-tokens.ts`, shadcn/ui primitives mapped onto those tokens, security headers + CSP nonce in `src/proxy.ts`. No auth, storage adapter, DAL or domain logic yet - those are M1+. Everything self-hosted: Caddy → app → Postgres in Compose.

**Tech Stack:** Node 24.21.0 · pnpm 10.34.5 · Next 16.3.8 · React 19.3.0 · TypeScript 7.0.2 (fallback 6.0.3) · Tailwind 4.3.3 · shadcn CLI 4.21.0 · Prisma 7.10.0 + `@prisma/adapter-pg` · PostgreSQL 18.6 · Zod 4.6.5 + `@t3-oss/env-nextjs` 0.13.11 · Vitest 5.0.3 · Playwright 1.63.0 · ESLint 10.11.0 · Prettier 3.9.9 · `@google/design.md` 0.4.0 · Caddy 2.11.4

**Spec:** `IMPLEMENTATION_PLAN_v2.md` (§3 versions, §5 layout, §7.2 schema, §9-§10 auth boundary, §14 security, §15 env, §16 Docker, §18 CI, §24 design) and `SPEC.md` §6 (non-functional requirements). `DESIGN.md` is the token source. `CLAUDE.md` holds the non-negotiable rules - read it first.

## Global Constraints

- Node `24.21.0` (`.node-version`), pnpm `10.34.5`; `engines.node >= 24`, `.npmrc` has `engine-strict=true` and `save-exact=true`. The dev machine currently runs Node 22.21.1 - switch before Task 1 (`fnm use 24.21.0` or `nvm use 24.21.0`).
- Every dependency pinned to an exact version. Versions below were verified against npm/Docker Hub on 2026-09-30/10-01; if a `pnpm add` reports a version does not exist, use `npm view <pkg> version` and pin what it prints, and note it in the commit.
- ESM project: `"type": "module"` in `package.json` (Prisma 7 requirement).
- No hex colour literals in `src/app/**` or `src/components/**`; all colours via generated Tailwind utilities (v2 §24.1). `src/app/tokens.css` is generated, committed, and must match `DESIGN.md` + `DESIGN.light.md` (`pnpm design:tokens --check`).
- No secrets in the repo. `.env` is gitignored; `.env.example` is the contract; `scripts/gen-secrets.sh` produces real values.
- Money, dates, auth, storage rules in `CLAUDE.md` apply to any code written here even though M0 has almost none of that logic.
- Conventional commits; commit after every task; never push unless asked.
- Next 16: `src/proxy.ts` (not `middleware.ts`); `next lint` does not exist - `eslint .`.
- Both themes must render: `:root` (dark) and `[data-theme="light"]`.

## Review Focus

1. `DESIGN.light.md` declares a colour token that does not exist in `DESIGN.md` (typo) - the generator must fail with the token name, never silently emit an orphan variable. *(pinned in Task 3)*
2. A `okinvo.theme` cookie holding garbage (`"blue"`, empty, URL-encoded junk) - page still renders, treated as `system`. *(pinned in Task 4)*
3. `AUTH_ALLOWED_EMAILS=" Me@Example.COM, *@Corp.io ,"` - whitespace/case/trailing comma normalised, matching is case-insensitive, a bare `*` or `*@` is rejected at boot. *(pinned in Task 5)*
4. Postgres down or hanging - `/api/health/ready` returns 503 within ~1 s instead of holding the connection; `/api/health/live` stays 200. *(pinned in Task 7)*
5. Two requests get two different CSP nonces, and `'unsafe-eval'` appears only outside `NODE_ENV=production`. *(pinned in Task 7)*

describe("parseFrontMatter", () => {
  it("returns the YAML tokens", () => {
    const t = parseFrontMatter(dark);
    expect(t.colors.canvas).toBe("#010102");
    expect(t.rounded?.md).toBe("8px");
  });
  it("throws without front matter", () => {
    expect(() => parseFrontMatter("# no tokens")).toThrow(/front matter/);

describe("toTokensCss", () => {
  const css = toTokensCss(parseFrontMatter(dark), parseFrontMatter(light));
  it("emits dark colours inside @theme and resets Tailwind's palette", () => {
    expect(css).toContain("@theme {");
    expect(css).toContain("  --color-*: initial;");
    expect(css).toContain("  --color-canvas: #010102;");
  });
  it("emits light overrides under [data-theme=light] only for declared keys", () => {
    const light = css.split('[data-theme="light"] {')[1] ?? "";
    expect(light).toContain("--color-canvas: #ffffff;");
    expect(light).not.toContain("--color-ink");
  });
  it("emits typography as --text-* with sub-values, radius and spacing", () => {
    expect(css).toContain("  --text-app-body: 14px;");

    expect(css).toContain("  --radius-md: 8px;");
    expect(css).toContain("  --spacing-md: 16px;");
  });
  it("rejects a light token that does not exist in dark (typo protection)", () => {
    const bad = parseFrontMatter(`---\nname: x\ncolors:\n  canvsa: "#ffffff"\n---\n`);

  });

    const bad = parseFrontMatter(`---\nname: x\ncolors:\n  canvas: "white"\n---\n`);
    expect(() => toTokensCss(bad, parseFrontMatter(light))).toThrow(/canvas/);
  });

import { existsSync, readFileSync, writeFileSync } from "node:fs";
import { resolve } from "node:path";
import { pathToFileURL } from "node:url";
import { parse } from "yaml";

export interface Typography {
  fontFamily: string;
  fontSize: string;
  fontWeight?: number;
  lineHeight?: number | string;
  letterSpacing?: number | string;
  fontFeature?: string;
}
export interface DesignTokens {
  name: string;
  colors: Record<string, string>;
  typography?: Record<string, Typography>;
  rounded?: Record<string, string>;
  spacing?: Record<string, string | number>;
}

const HEX = /^#[0-9a-fA-F]{6}$/;

/** Font stacks per v2 §24.5 - DESIGN.md's documented substitutes for Linear's proprietary faces. */
export const FONT_STACKS = {
  sans: `"Inter Variable", "SF Pro Display", -apple-system, system-ui, "Segoe UI", Roboto, sans-serif`,
  mono: `"JetBrains Mono", "SF Mono", ui-monospace, Menlo, monospace`,
} as const;

export function parseFrontMatter(markdown: string): DesignTokens {
  const match = /^---\r?\n([\s\S]*?)\r?\n---/.exec(markdown);
  if (!match) throw new Error("No YAML front matter found (expected a leading --- block)");
  const data = parse(match[1] ?? "") as Partial<DesignTokens>;
  if (!data || typeof data !== "object" || !data.colors) throw new Error("front matter has no colors block");
  return data as DesignTokens;
}

const px = (v: number | string) => (typeof v === "number" ? `${v}px` : v);

export function toTokensCss(dark: DesignTokens, light: DesignTokens): string {
  for (const [k, v] of Object.entries(dark.colors)) {
    if (!HEX.test(v)) throw new Error(`DESIGN.md colors.${k} must be a 6-digit hex, got "${v}"`);
  }
  for (const [k, v] of Object.entries(light.colors)) {
    if (!(k in dark.colors)) throw new Error(`DESIGN.light.md defines colors.${k}, which does not exist in DESIGN.md`);
    if (!HEX.test(v)) throw new Error(`DESIGN.light.md colors.${k} must be a 6-digit hex, got "${v}"`);
  }

  const out: string[] = [
    "/* GENERATED by scripts/design-tokens.ts from DESIGN.md + DESIGN.light.md - do not edit by hand. */",
    "@theme {",
    "  --color-*: initial;",
  ];
  for (const [k, v] of Object.entries(dark.colors)) out.push(`  --color-${k}: ${v};`);
  out.push(`  --font-sans: ${FONT_STACKS.sans};`);
  out.push(`  --font-mono: ${FONT_STACKS.mono};`);
  for (const [k, v] of Object.entries(dark.rounded ?? {})) out.push(`  --radius-${k}: ${v};`);
  for (const [k, v] of Object.entries(dark.spacing ?? {})) out.push(`  --spacing-${k}: ${px(v)};`);
  for (const [k, t] of Object.entries(dark.typography ?? {})) {
    out.push(`  --text-${k}: ${t.fontSize};`);
    if (t.lineHeight !== undefined) out.push(`  --text-${k}--line-height: ${t.lineHeight};`);
    if (t.fontWeight !== undefined) out.push(`  --text-${k}--font-weight: ${t.fontWeight};`);
    if (t.letterSpacing !== undefined) out.push(`  --text-${k}--letter-spacing: ${px(t.letterSpacing)};`);
  }
  out.push("}", "", `:root[data-theme="light"] {`); // :root[…] outranks Tailwind's own :root emission of the dark values
  for (const [k, v] of Object.entries(light.colors)) out.push(`  --color-${k}: ${v};`);
  out.push("}");
  return out.join("\n") + "\n";
}

function main(): void {
  const root = resolve(import.meta.dirname, "..");
  const dark = parseFrontMatter(readFileSync(resolve(root, "DESIGN.md"), "utf8"));
  const light = parseFrontMatter(readFileSync(resolve(root, "DESIGN.light.md"), "utf8"));
  const css = toTokensCss(dark, light);
  const target = resolve(root, "src/app/tokens.css");
  if (process.argv.includes("--check")) {
    const current = existsSync(target) ? readFileSync(target, "utf8") : "";
    if (current !== css) {
      console.error("src/app/tokens.css is stale - run `pnpm design:tokens` and commit the result");
      process.exit(1);
    }
    console.log("src/app/tokens.css is up to date");
    return;
  }
  writeFileSync(target, css);
  console.log(`wrote ${target}`);
}

if (process.argv[1] && import.meta.url === pathToFileURL(process.argv[1]).href) main();

export type ThemeMode = "dark" | "light" | "system";
export type ResolvedTheme = "dark" | "light";

export function parseThemeMode(value: string | undefined | null): ThemeMode {
  return value === "dark" || value === "light" || value === "system" ? value : "system";
}

/** Server-rendered attribute. `system` starts dark; THEME_INIT_SCRIPT corrects it before first paint. */
export function initialTheme(mode: ThemeMode): ResolvedTheme {
  return mode === "light" ? "light" : "dark";

const DOMAIN = /^[a-z0-9.-]+\.[a-z]{2,}$/;
const EMAIL = /^[^\s@]+@[a-z0-9.-]+\.[a-z]{2,}$/;

/** Parses AUTH_ALLOWED_EMAILS: comma-separated exact addresses and `*@domain` patterns. Throws on malformed entries. */
export function parseAllowedEmails(raw: string | undefined): AllowList {
  const emails = new Set<string>();
  const domains = new Set<string>();
  for (const part of (raw ?? "").split(",")) {
    const original = part.trim();
    const entry = original.toLowerCase();
    if (!entry) continue;
    if (entry.startsWith("*@")) {
      const domain = entry.slice(2);
      if (!DOMAIN.test(domain)) throw new Error(`AUTH_ALLOWED_EMAILS: invalid domain pattern "${original}"`);
      domains.add(domain);
      continue;
    }
    if (!EMAIL.test(entry)) throw new Error(`AUTH_ALLOWED_EMAILS: invalid entry "${original}"`);
    emails.add(entry);
  }
  return { emails, domains };
}

export function isAllowedEmail(email: string, list: AllowList): boolean {
  const normalised = email.trim().toLowerCase();
  const at = normalised.lastIndexOf("@");
  if (at < 1 || at === normalised.length - 1) return false;
  return list.emails.has(normalised) || list.domains.has(normalised.slice(at + 1));
}

export interface CspOptions {
  nonce: string;
  isProd: boolean;
  /** Extra origins allowed as form-action targets (identity providers, added in M1). */
  formActionOrigins?: string[];
}

export function buildCsp({ nonce, isProd, formActionOrigins = [] }: CspOptions): string {
  const directives = [
    "default-src 'self'",
    `script-src 'self' 'nonce-${nonce}' 'strict-dynamic'${isProd ? "" : " 'unsafe-eval'"}`,
    "style-src 'self' 'unsafe-inline'",
    "img-src 'self' data: blob:",
    "font-src 'self'",
    isProd ? "connect-src 'self'" : "connect-src 'self' ws: wss:",
    "frame-ancestors 'none'",
    "base-uri 'self'",
    `form-action 'self'${formActionOrigins.map((o) => ` ${o}`).join("")}`,
    "object-src 'none'",
  ];
  if (isProd) directives.push("upgrade-insecure-requests");
  return directives.join("; ");
}

export function securityHeaders({ csp, https }: { csp: string; https: boolean }): [string, string][] {
  const headers: [string, string][] = [
    ["Content-Security-Policy", csp],
    ["X-Content-Type-Options", "nosniff"],
    ["Referrer-Policy", "strict-origin-when-cross-origin"],
    ["Permissions-Policy", "camera=(), microphone=(), geolocation=()"],
    ["Cross-Origin-Opener-Policy", "same-origin"],
    ["X-Frame-Options", "DENY"],
  ];
  if (https) headers.push(["Strict-Transport-Security", "max-age=31536000; includeSubDomains"]);
  return headers;
}

import { NextResponse, type NextRequest } from "next/server";
import { buildCsp, securityHeaders } from "@/lib/security-headers";

export function proxy(request: NextRequest): NextResponse {
  const nonce = Buffer.from(crypto.getRandomValues(new Uint8Array(16))).toString("base64");
  const csp = buildCsp({ nonce, isProd: process.env.NODE_ENV === "production" });

  // Next reads the CSP from the *request* headers to nonce its own inline scripts;
  // the layout reads x-nonce for the theme script.
  const requestHeaders = new Headers(request.headers);
  requestHeaders.set("x-nonce", nonce);
  requestHeaders.set("Content-Security-Policy", csp);

  const response = NextResponse.next({ request: { headers: requestHeaders } });
  const https = request.headers.get("x-forwarded-proto") === "https" || request.nextUrl.protocol === "https:";
  for (const [key, value] of securityHeaders({ csp, https })) response.headers.set(key, value);
  return response;
}

export type Readiness = { status: 200 | 503; body: { ok: boolean; db: "ok" | "timeout" | "error" } };

/** Runs `probe` with a hard time budget so a wedged database yields a fast 503 instead of a hung request. */
export async function checkReadiness(probe: () => Promise<unknown>, timeoutMs: number): Promise<Readiness> {
  let timer: ReturnType<typeof setTimeout> | undefined;
  const timeout = new Promise<"timeout">((resolve) => {
    timer = setTimeout(() => resolve("timeout"), timeoutMs);
  });
  try {
    const outcome = await Promise.race([probe().then(() => "ok" as const), timeout]);
    return outcome === "ok" ? { status: 200, body: { ok: true, db: "ok" } } : { status: 503, body: { ok: false, db: "timeout" } };
  } catch {
    return { status: 503, body: { ok: false, db: "error" } };
  } finally {
    if (timer) clearTimeout(timer);
  }
}
